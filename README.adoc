== descriptions
* allows you to find things not always easy to determine on a installed jvm
** which is the JVM vendor ? (Oracle, RedHat, IBM, temurin, AdoptOpenJdk, ...)
** what is the java language version supported
** what is the precise version of the package (up to build number)
** what is the minimal supported class version
** what is the OS the jvm runs on (though `os.name` and `os.vesion`)
** is it a jre only version, or a full jdk

== going 1.0

----
● Yes, the maven-compiler-plugin supports Jikes via the compilerId:

  <plugin>
    <groupId>org.apache.maven.plugins</groupId>
    <artifactId>maven-compiler-plugin</artifactId>
    <configuration>
      <compilerId>jikes</compilerId>
      <source>1.1</source>
      <target>1.1</target>
    </configuration>
  </plugin>
  <plugin>
    <groupId>org.codehaus.plexus</groupId>
    <artifactId>plexus-compiler-jikes</artifactId>
    <version>1.9.2</version>
  </plugin>

  The plexus-compiler-jikes artifact bridges Maven and Jikes. That said, it's very old and may have compatibility issues with newer Maven versions. Worth trying if you get Jikes installed.

❯ do I need a version of jikes on the machine ?

● Yes — plexus-compiler-jikes is just a bridge; it still calls the jikes binary on the machine. So you need Jikes installed and on the PATH.
